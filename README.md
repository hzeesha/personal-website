# hzeesha.dev

This is my personal portfolio site: a place to show who I am, what I’ve worked on, and how to reach me.

## What’s on the site

- Animated particle background using `particles.js`
- Fixed navbar with smooth scrolling between sections
- About section with a short intro and profile photo
- Experience section with clickable cards that open detailed popups
- Projects grid linking to live apps and GitHub repos
- Contact form hooked up to Formspree

## Tech

- HTML5  
- CSS3 (layout, animations, responsive design)  
- Vanilla JavaScript (modals, navbar toggle, form handling)  
- `particles.js` for the background animation

## File Overview

- `index.html` – main page markup  
- `styles.css` – styles and responsive rules  
- `app.js` – particles config + interaction logic  
- `particles.js` – particles.js library  
- `particle-cfg.json` – extra particle config (not required to run)  
- `images/` – logos, profile image, and project thumbnails  

## How to run

Clone the repo and open `index.html` in your browser:

```bash
git clone https://github.com/hzeesha/your-repo-name.git
cd your-repo-name
```
